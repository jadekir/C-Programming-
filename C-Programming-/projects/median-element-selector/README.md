# Median Element Selector

This program reads an odd-length list of numbers from a file and returns the middle element after sorting.

It is a smaller assignment, but I included it because it shows file input, dynamic allocation, sorting with `qsort`, and working with larger unsigned integer values.

Run:

```sh
gcc -o median_selector main.c
./median_selector
```

The sample input file is included as `pa4_data.txt`.
