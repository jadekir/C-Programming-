# C Programming Projects

This repo is a collection of C programs from my coursework. I cleaned it up so the larger assignments are easier to find instead of leaving everything as random class files.

Most of these were written for practice with pointers, files, structs, linked lists, stacks, tries, and lower-level computer architecture concepts.

## Projects

### Hill Cipher

Encrypts text with a Hill cipher key matrix. This was useful practice for file input, matrix math, and keeping text formatting under control.

Folder: `projects/hill-cipher`

### Checksum Calculator

Calculates 8-bit, 16-bit, or 32-bit checksums for an input file. This one connects more to security/networking because it is about checking data integrity.

Folder: `projects/checksum-calculator`

### Linked List Card Game

Uses linked lists and dynamic memory to manage card/player data. This was one of the better data structure assignments because it required more than just arrays.

Folder: `projects/linked-list-card-game`

### Trie Prefix Counter

Builds a trie from words and counts prefix matches. This was good practice with recursive structures and memory cleanup.

Folder: `projects/trie-prefix-counter`

### Polynomial Linked List Combiner

Combines polynomial terms stored in linked lists. The main focus was sorting, merging, and handling dynamically allocated nodes.

Folder: `projects/polynomial-linked-list-combiner`

### Infix to Postfix Converter

Uses a stack to validate expressions and convert infix notation to postfix notation.

Folder: `projects/infix-postfix-stack`

### MIPS ALU Simulator

Implements pieces of a MIPS-style simulator, including ALU behavior and instruction handling.

Folder: `projects/mips-alu-simulator`

## Notes

Some files still show the original class assignment names or comments because I wanted to keep the work close to how it was submitted. I renamed the folders so the projects are easier to understand on GitHub.
